# Sock pairing probability app 🧦📊

Ever wondered how many socks you need to pull from your drawer to guarantee a matching pair? This fun little app dives into the world of probability with a sock twist!

<img src="https://github.com/andrewliew86/Sock-pairing-probability-explorer/blob/main/images/app_img.PNG">

## Features
- Calculate the minimum socks needed for a match
- Interactive sliders for different scenarios
- Visual charts to make math fun (or at least tolerable)
- Built with React, TypeScript, and Vite for that snappy performance

## Getting Started
1. Clone this repo (or just enjoy it locally)
2. Run `npm install` to grab the goodies
3. Fire it up with `npm run dev`
4. Open your browser and start sock-probability-ing!

## Why Socks?
Because I often find myself wondering why I ended up with two left socks instead of a correct pair 🧦🎉

*Note: This app was vibe coded using GPT 5.2 and won't actually help you find your missing socks. Sorry!*
